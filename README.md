# Merge Madness

A merge game for Miles. Drag two matching gems together to make a bigger one and earn pretend coins, then spend them in the shop.

Coins are pretend. No real money, ads, accounts, or data collection.

## Play

```
npm install
npm run dev
```

## Change the numbers

Everything you can tweak (coins per tier, shop prices, spawn odds) is in `src/config.ts`.
